# montazh-lite

## Установка

**Самый простой способ.** Скопируйте ссылку на эту страницу, вставьте её в Claude Code и напишите: «Установи мне этот скилл». Claude сам скачает скилл и положит куда нужно. Файлы ниже открывать не нужно.

Вручную, Mac и Windows (Git Bash), две команды (первая создаёт папку для скиллов, если её ещё нет):

```
mkdir -p ~/.claude/skills
git clone https://github.com/guzhovpro-code/montazh-lite.git ~/.claude/skills/montazh-lite
```

Windows PowerShell:

```
New-Item -ItemType Directory -Force "$HOME\.claude\skills"
git clone https://github.com/guzhovpro-code/montazh-lite.git "$HOME\.claude\skills\montazh-lite"
```

Без git: скачайте ZIP с этой страницы (Code, Download ZIP), распакуйте и положите папку в `~/.claude/skills/` под именем `montazh-lite`. Скилл появится в Claude Code после перезапуска.

Скилл Claude Code: первый шаг монтажа ролика, где вы говорите в камеру. Он чистит ролик, чтобы на него можно было накладывать эффекты: вырезает паузы, чистит звук и делает зум на склейках. Бесплатно, на вашем компьютере, без ключей и скачиваний.

**Две остановки вы проходите сами: «кусок 15 секунд» и «готовый ролик». Скилл показывает результат и ждёт вашего ответа.**

## Кому и когда поможет

У вас есть сырая запись: вы говорите в камеру, в речи паузы, звук гуляет по громкости. Нужен чистый ролик, на который дальше ляжет оформление, за 10 минут, а не за вечер в монтажной программе.

**Что получится.** Рядом с вашим файлом ляжет `имя-montazh.mp4`: паузы длиннее 0,45 секунды сжаты до 0,2 (на нашем тестовом ролике 37 секунд стали 16, на другом 83 стали 59), громкость как на YouTube (−16 LUFS), шумоподавление лёгкое, каждый второй кусок чуть крупнее, чтобы склейки не бросались в глаза (самый первый кусок всегда без увеличения, а куски короче 0,7 секунды остаются с масштабом соседнего, чтобы не дёргалось). Оригинал не тронут: скилл откажется, если имя результата совпадает с вашим файлом, и не затрёт уже готовый результат без флага `--force`. Результат всегда mp4 (видео H.264, звук AAC), размер и частота кадров как у исходника (шире 1920 пикселей уменьшается до 1920). Принимается файл с видео и звуком, который читает ffmpeg и по которому видны частота кадров и длительность. Частота кадров берётся номинальная из файла: у записей с переменной частотой на выходе она станет постоянной.

**Чего скилл не делает.** Не накладывает субтитры, анимацию и эффекты: это делается во втором скилле. Не ищет оговорки и дубли по смыслу, режет только тишину. Не следит за тем, куда вы смотрите и моргаете ли в момент склейки: на стыке может мелькнуть закрытый глаз. Звук на слух не оценивает: громкость проверена числами, как звучит, послушаете сами.

## Что вы увидите

Время ниже снято на настоящем прогоне (Windows 11, без видеокарты). Ваше время на ответы не считается.

1. **Старт, около минуты.** Вы пишете: «Почисти моё видео по скиллу montazh-lite» и называете файл. Claude проверит, что на компьютере есть Python и ffmpeg (бесплатная программа для видео), при необходимости предложит поставить и спросит разрешения. Ещё он спросит, можно ли посмотреть один-два кадра вашего видео: по ним он находит лицо, чтобы навести зум. Кадры уходят в модель Claude по правилам вашей подписки. Само видео никуда не отправляется.
2. **Первый прогон на куске 15 секунд.** Он занимает меньше минуты (у нас около 8 секунд). Claude даст путь к файлу, вы смотрите и отвечаете: паузы и зум подходят? Что поправить?
3. **Правки вкуса.** Скажите словами: «паузы режет резко», «слишком дёргано», «зум бросается в глаза». Claude запишет это в файл настроек `taste.json` (таблица в `references/taste.md`) и перегонит кусок.
4. **Готовый ролик.** Монтаж ролика в 37 секунд занял у нас около 10 секунд, ролика в 83 секунды около 36. Потом Claude печатает отчёт: громкость, самая длинная тишина, склейки без повторных и пустых кадров, лицо не обрезано зумом. Вы смотрите файл и говорите «принимаю». Правка выйдет новым файлом, старый останется.

## Куда скилл пишет

Скилл пишет результат туда, куда указали вы (`--out`: относительный путь считается от текущей папки, абсолютный и `..` принимаются как есть), и читает `taste.json` из текущей папки. Он отказывается писать поверх вашего исходника, поверх готового результата без `--force` и через символические ссылки и junction. Границы «только внутри папки проекта» нет: указывайте папку сами.

## Как учить скилл вкусу

Не нужно разбираться в настройках. Говорите как есть: «паузы режет слишком резко», «зум бросается в глаза», «звук шумит». Claude переведёт это в числа и запишет в `taste.json` в папке проекта. Следующий ролик возьмёт эти настройки сам.

## Что нужно

Claude Code (подойдёт любая модель) и две программы, которых у вас может не быть: ffmpeg (полная сборка, с кодировщиками H.264 и AAC) и Python 3.10 или новее. Если их нет, Claude предложит поставить и спросит разрешения (Windows `winget install Python.Python.3.12` и `winget install Gyan.FFmpeg`, Mac `brew install python ffmpeg`, Linux `sudo apt install python3 ffmpeg`). Больше ничего: скрипты написаны на стандартной библиотеке Python, ничего не скачивают и не требуют ключей. Windows или Mac. На Windows 11 полный прогон был. На Mac скрипты не запускались: ожидаем, что работают (они не используют ничего, чего нет на Mac), но не проверяли.

## Что проверено, а что нет

Проверено числами на двух настоящих роликах (говорящая голова, 1920×1080, 50 кадров в секунду): громкость, паузы, склейки, длина, лицо не обрезано зумом. Python прогнан на версиях 3.11 и 3.12, на 3.9 не запускали (поэтому в требованиях 3.10). Не проверено: как звучит и выглядит на глаз у других людей, вертикальная съёмка с телефона, 10 бит и HDR, Mac, видео длиннее 5 минут. Чужая лицензия: ffmpeg (LGPL/GPL, вы ставите его сами, в скилл он не входит).
